## 2024-05-18 - Avoid unnecessary prop check logic inside React effect when variable exists in deps array\n**Learning:** Implementing `isAppliedRef` to avoid setting model materials redundantly is an anti-pattern when React `useLayoutEffect` explicitly triggers only when dependencies (like the color variable) change. Attempting to manual short-circuit causes visual bugs, especially when a property needs to transition dynamically like the hover effects.\n**Action:** Let React manage dependency-based execution for effects.
